# agro-sentinel-gis

Owner: Amudhan S (GIS and Remote Sensing). Pilot area: Botolan, Zambales.

## Folders
- nasa-challenge/  : NASA data and boundary for the Nov 14-15 competition
                     (AgriMind AI). Start with nasa-challenge/README.md
- sammium-research/: longer research work: GPM IMERG, spatial "blur"
                     analysis, progress log

## Setup (Windows, 64-bit Python 3.12)
  py -3.12 -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
Never commit passwords. Large data files are not in git.
